# Project Title

CMS

## Instructions for Build and Use

[Software Demo Video](https://www.youtube.com/watch?v=ExVHsqye2EU)

Steps to build and/or run the software:

1. Run "git clone https://github.com/pavelwebdeveloper/cms.git" locally on your computer in CMD
2. Make sure that you have node.js and angular installed with the right versions
3. Install dependencies
4. Run "ng serve" and "node server.js" in CMD inside 
5. Open the app in your browser according to the local host mentioned by "ng serve"

Instructions for using the software:

1. There is a heading with three links "Documents Messages Contacts" 
2. You can navigate these links and see either documents or messages or contacts
3. You can click on documents or on contacts and see information for each of them

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Visual Studio Code
* node.js version 20.20.2 (64-bit)
* npm 9.4.2
* Angular CLI: 20.3.23
